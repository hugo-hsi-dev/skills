# Shared site brief

Design and build a polished, self-contained single-page website for **Silt**, an offline-first research notebook for ecologists and conservation teams. It captures field observations, photos, and GPS coordinates without a connection, then syncs safely when the team returns online.

The audience is working field researchers, principal investigators, and research-operations leads. The primary conversion is **Start free**.

Include navigation, a hero with a self-contained product demonstration, core capabilities, an explanation of offline sync, one field-researcher testimonial, simple individual and team pricing, a final call to action, and a footer.

Technical constraints:

- Produce one self-contained `index.html` using HTML, CSS, and basic inline JavaScript only if useful.
- Do not use external assets, fonts, libraries, or network requests. CSS and inline SVG are allowed.
- Make it responsive and accessible.
- It should render well at 1440×900 and 390×844.
- Do not provide an explanation. Write the completed site to the specified path.

# Shared benchmark prompt

Design and build a polished, self-contained single-page website for **Aperture Field**, a compact handheld daylight meter for working photographers and cinematographers.

The product should feel precise, tactile, field-ready, and quietly distinctive. The audience values reliable tools and visual craft, but the site still needs to communicate the product clearly and drive pre-orders.

Include:

- navigation;
- a hero with a clear pre-order action and a convincing product visual;
- three core product proof points;
- a short explanation of how it works;
- one field quote;
- a compact specifications section;
- a final call to action and footer.

Technical constraints:

- Produce one self-contained `index.html` using HTML, CSS, and basic inline JavaScript only if useful.
- Do not use external assets, fonts, libraries, or network requests. CSS and inline SVG are allowed.
- Make it responsive and accessible.
- It should render well at 1440×900 and 390×844.
- Do not provide an explanation. Write the completed site to the requested `index.html` path.
